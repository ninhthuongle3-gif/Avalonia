# 余晖之后

原创像素风 2D 横版丧尸末日塔防原型，使用 Godot 4.6.3。玩家扮演营地指挥官，在白天分配废料、建造工事和招募队伍，夜晚抵御不断增强的尸潮。

视觉方向参考《恐怖僵尸夜》的阴暗末世氛围与横版群体场景；角色、建筑、场景均由原创程序化像素图形绘制，不含该作品的素材。

## 启动

在 Godot 4.6.3 中打开 `project.godot` 并按 F5，或在图形桌面运行 `bash run.sh`。游戏使用中文界面；系统需提供中文字体（当前云环境已有 Noto CJK）。无第三方插件和联网服务。

## 玩法

- 点击地面 1–4 号工位，建造路障（35 废料）或自动射击的哨戒塔（85）。路障耐久更高。
- 招募枪手（55 废料）或医护（70），每人消耗 1 份口粮，最多 8 人。医护在战斗中缓慢恢复营地耐久。
- 营地维修花费 40 废料，恢复 130 耐久。建设、招募、维修只能在波次之间进行。
- 空格开始下一波；P 暂停/继续；营地失守后 R 重建。
- 击杀获得废料，清空一波额外奖励废料和口粮；第二波出现奔跑者，第三波出现重型感染者。

建议首波在 1 号位建塔、2 号位建路障，之后利用奖励招募队伍并向外扩展防线。

## 验证

```sh
bash run.sh --headless --editor --import --quit
bash run.sh --headless --script tests/game_test.gd
bash run.sh --headless --quit-after 120
```

测试覆盖资源扣除、防重复建设、招募约束、战时建设限制、暂停、真实首波战斗与奖励、医护、失守重开和敌人升级。无界面测试不验证画面输出。

当前为单场景玩法原型：无限递增波次，没有存档、科技树、远征、音效、正式美术素材或发布安装包。源项目 `/workspace/Avalonia` 保持独立。
