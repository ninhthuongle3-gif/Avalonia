# v0.2：惯性动作、骨骼与丧尸 AI

## 本轮修改

1. **减少滑步**：脚步周期按实际碰撞后位移推进，站立支撑脚保存在世界坐标中；髋、膝、踝的两段 IK 解算支撑与摆动。撞墙时停止步态，刹停时用收步动作恢复站姿。冲刺采用更长步幅、更短支撑时间和更高抬脚。
2. **移动惯性与姿态**：行走逐渐加速至 4.4 m/s，冲刺至 7.4 m/s，松键后减速；反向移动先抵消原速度。躯干按局部加速度前后倾、侧倾，冲刺、跳跃、落地、换弹、受伤都有独立姿态层。
3. **骨骼**：真正的 30 骨骼 `Skeleton3D`，包含骨盆、脊柱、胸、颈、头、锁骨、上臂、前臂、手、食指、拇指、大腿、小腿、脚、脚趾、两段马尾和衣摆。各部位是 `BoneAttachment3D` 插槽，手臂 IK 跟随真实握把与换弹目标。F3 可显示关节位置。当前仍是程序化占位模型与动作，不含正式蒙皮模型或动捕资源。
4. **自由 / 瞄准**：默认放低枪，无准星，镜头可以独立转动，移动时角色转向实际行进方向。按住右键逐渐举枪、将身体对准镜头；举枪完成后出现准星，才允许左键射击。瞄准时以 2.05 m/s 慢步移动，不能冲刺；松开右键恢复自由状态。
5. **丧尸 AI**：巡逻、视野与视线检测、枪声调查、目标记忆、基于 AStarGrid2D 的绕障路径、角色碰撞、群体分离、追击、0.58 秒攻击前摇、攻击后恢复、受击硬直、死亡及尸体清理。近战在实际命中时重新检查距离、高度和墙体遮挡。

## 操作与流程

启动默认进入三波生存模式，共 4、6、8 只感染者，后续波次混入奔跑型。玩家有 100 点生命，受伤后有短暂无敌时间，波次开始补充备用弹药。清空第三波结束，死亡或通关后 Enter 重开。

| 操作 | 按键 |
| --- | --- |
| 移动 / 冲刺 / 跳跃 | WASD / Shift / Space |
| 自由视角 | 鼠标 |
| 举枪瞄准 / 射击 | 按住右键 / 瞄准完成后按左键 |
| 换肩 / 换弹 | Q / R |
| 重开当前模式 | T |
| 生存模式 / 六靶训练 | F2 |
| 骨骼关节显示 | F3 |
| 暂停、释放鼠标 / 恢复 | Esc / Enter 或 Esc |
| 静音 | M |

## 验证

从仓库根目录执行：

```sh
./run.sh --headless --editor --import --quit
./run.sh --headless --script tests/tps_test.gd
./run.sh --headless --script tests/tps_locomotion_test.gd
./run.sh --headless --script tests/tps_ai_test.gd
```

- 原有 3D 射击、镜头、训练检查：41 项。
- 动作、惯性、瞄准和骨骼检查：21 项。使用真实脚部骨骼而非期望目标测量支撑漂移；本次行走支撑帧最大漂移约 0.8 毫米，冲刺支撑帧接近零，双手握把误差接近零。这些是选定平地场景中的自动检查，不代表所有地形和动作组合完全无滑步。
- AI 与生存流程检查：28 项，包含真实碰撞体绕掩体、攻击前摇、躲避、墙体阻挡、受击打断、真实枪口射线伤害、死亡重开及三波通关。

本次导出的 Windows PCK 也在云端 Godot 中通过上述全部 90 项检查；这验证分发资源中的游戏逻辑，不代表 Windows EXE 已完成实机测试。

有图形显示时运行 `./run.sh --rendering-method gl_compatibility --audio-driver Dummy --script tests/tps_visual.gd`，将九种真实渲染视图写入 `artifacts/`。云端使用 Mesa llvmpipe；不据此宣称 Windows 实机性能。

## 导出

已提供 `export_presets.cfg`。安装官方 Godot 4.6.3 对应导出模板后：

```sh
mkdir -p exports/windows
./run.sh --headless --export-release "Windows Desktop" exports/windows/LastLight.exe
```

分发时将 `LastLight.exe`、`LastLight.pck`、操作说明、引擎及字体许可一起打包。此次 GitHub 试玩包使用带版本号的文件名，避免与上一版混淆。

## 当前限制

角色与丧尸是几何占位内容，动作由代码解算，没有正式角色美术、动捕、布料或布娃娃。导航网格针对当前静态平面场地生成；未来加入可破坏掩体、楼梯和多层关卡时需要更新导航与脚底解算。自动测试验证逻辑与指定动作的脚部稳定性，最终操作手感仍需试玩反馈。
