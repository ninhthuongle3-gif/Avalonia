# LAST LIGHT / 最后灯火

丧尸末日题材的 2D 横版射击原型，使用 **Godot 4.6.3** 开发。无第三方插件、无联网服务、无运行时下载。建议使用相同版本的 Godot；项目采用 GL Compatibility 渲染器。

本轮重点是可以持续调整的操作与反馈基础：AI 生成并拆分的角色部件、`Skeleton2D/Bone2D` 骨骼、带惯性的移动和程序化步态、鼠标瞄准、武器熟练度、步枪与手枪切换、举盾、受击硬直、爆头和波次生存。角色保留白发、头盔、重甲和大盾特征；当前美术已达到可测试的精细原型阶段，仍可继续修图和增加逐帧辅助动画。

## 运行

使用 Godot 4 打开 `project.godot`，按 F6 或 F5 启动。Linux / macOS 也可以运行：

```sh
./run.sh
```

在纯命令行云环境，运行逻辑测试；实际操作需要有图形显示的电脑。当前云环境也可以通过虚拟显示器检查渲染。

```sh
./run.sh --headless --editor --import --quit
./run.sh --headless --script tests/combat_test.gd
./run.sh --headless --script tests/input_test.gd
```

`run.sh` 自动把 Godot 的用户数据、配置和缓存放到可写目录，无须修改系统设置。第一次打开会生成忽略的 `.godot/` 导入缓存。

## 操作

| 操作 | 按键 |
| --- | --- |
| 开始 / 死亡后重开 | Enter |
| 左右移动 | A / D，或方向键 |
| 瞄准 / 射击 | 鼠标 / 左键；步枪全自动，手枪半自动 |
| 切换武器 | 1 步枪、2 手枪，或 Q 循环切换 |
| 举盾 | 按住右键，防护正面，无法同时开枪 |
| 换弹 | R，空弹匣点击射击也会自动换弹 |
| 跳跃 / 冲刺 | Space / Shift |
| 暂停 / 帮助 | Esc / F1 |
| 静音 / 减少动态效果 | M / V |

子弹从枪口发出，命中最近的目标。AR-07 使用 5.56 弹药、24 发弹匣和全自动射击；P-9 使用 9×19 弹药、15 发弹匣和半自动射击。两把武器分别保存弹匣余量。低熟练度持续全自动射击会累积后坐力、让实际准星上移并扩大弹着范围；命中和爆头会提高当前武器熟练度，最高 5 级。半自动手枪没有持续连射惩罚，枪口恢复也更快。盾牌会减速并消耗体力，不能挡住背后的攻击；丧尸攻击有可见前摇。清空每波后休息 4 秒，下一波回复 15 点生命。

## 已实现的反馈

- 透明角色部件拆分：头部、长发、躯干、腰胯、前后侧四肢、盾牌、步枪和手枪；保留完整原始部件表便于返修。
- 15 个以上 `Bone2D` 组成的切片骨骼：头、躯干、手臂、前臂、大腿、小腿、靴子、盾牌和武器分别绑定。
- 移动加速、刹车惯性、转身阻力、奔跑身体前倾、空中控制、跳跃缓冲、落地尘土和脚步声。
- 射击抬枪前摇、射后恢复、跟随瞄准的双臂、武器切换收放动作、枪口焰、枪口上抬、准星扩散、曳光线、弹壳与换弹动作。
- 数据驱动武器参数：射击模式、弹种、射速、弹匣、换弹、伤害、单发后坐力、持续射击惩罚和恢复速度。
- 身体 / 头部命中判定、命中标记、短暂停顿、击退、硬直、击倒、伤害边缘反馈和死亡统计。
- 举盾火花、金属反馈音、体力消耗与恢复；减少动态模式关闭震屏和命中停顿。
- 原创多层城市隔离区背景：月亮、天际线、废弃车辆、铁丝网、警戒路障、灯光和飘尘。
- 由代码合成的步枪、弹匣、脚步、命中、受伤与盾牌音效；可静音。

## 验证与限制

`tests/combat_test.gd` 直接运行真实战斗逻辑，检查骨骼绑定、移动惯性、奔跑前倾、动作前后摇、边界、跳跃、射击节奏、后坐力与熟练度、武器切换、目标遮挡、爆头、换弹、盾牌方向、无敌间隔、丧尸前摇、暂停、波次和重开。

`tests/input_test.gd` 通过 Godot 输入事件和实时物理循环，验证 Enter、移动键、跳跃、步枪连射、手枪单击、独立弹匣、武器数字键切换、举盾、换弹、暂停与恢复、帮助和减少动态模式。当前共 **65 项检查通过**，另已用真实 OpenGL 渲染并录制 300 帧战斗演示。

这是手感验证原型，尚无正式手绘逐帧动画、游戏手柄、联机、存档、移动端适配或独立安装包。场景中的车辆、围栏和路障目前是美术背景，不能当作实体掩体。只有地面和地图边界限制移动。美术与声音的最终品质，以及鼠标操作手感，仍需实际试玩迭代。

## 项目结构

- `scripts/main.gd`：固定时间步的战斗、角色控制、敌人行为和特效。
- `scripts/actor.gd`：角色状态、丧尸矢量绘制和骨骼动画参数。
- `scripts/cutout_rig.gd`：生成角色的 `Skeleton2D/Bone2D` 切片骨骼与动作混合。
- `scripts/environment.gd`：可复现的视差场景绘制。
- `scripts/hud.gd`：标题、HUD、准星、帮助和结算。
- `scripts/sound.gd`：原创合成音效。
- `tests/combat_test.gd`：无图形战斗测试。
- `tests/input_test.gd`：真实输入事件集成测试。
- `tests/visual_smoke.gd`：自动战斗演示与截图。
