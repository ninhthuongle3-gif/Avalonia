# LAST LIGHT / 最后灯火

丧尸末日题材的 2D 横版射击原型，使用 **Godot 4.6.3** 开发。无第三方插件、无联网服务、无运行时下载。建议使用相同版本的 Godot；项目采用 GL Compatibility 渲染器。

本轮重点是可以持续调整的操作与反馈基础：分层角色、程序化步态和手臂关节、鼠标瞄准、自动步枪、举盾、受击硬直、爆头和波次生存。角色保留白发、头盔、重甲、大盾的视觉特征；当前是原创简化分层图形，尚未制作参考图精度的正式角色动画。

## 运行

使用 Godot 4 打开 `project.godot`，按 F6 或 F5 启动。Linux / macOS 也可以运行：

```sh
./run.sh
```

在纯命令行云环境，运行逻辑测试；实际操作需要有图形显示的电脑。当前云环境也可以通过虚拟显示器检查渲染。

```sh
./run.sh --headless --editor --import --quit
./run.sh --headless --script tests/combat_test.gd
./run.sh --headless --script tests/input_test.gd
```

`run.sh` 自动把 Godot 的用户数据、配置和缓存放到可写目录，无须修改系统设置。第一次打开会生成忽略的 `.godot/` 导入缓存。

## 操作

| 操作 | 按键 |
| --- | --- |
| 开始 / 死亡后重开 | Enter |
| 左右移动 | A / D，或方向键 |
| 瞄准 / 连射 | 鼠标 / 左键 |
| 举盾 | 按住右键，防护正面，无法同时开枪 |
| 换弹 | R，空弹匣点击射击也会自动换弹 |
| 跳跃 / 冲刺 | Space / Shift |
| 暂停 / 帮助 | Esc / F1 |
| 静音 / 减少动态效果 | M / V |

子弹从枪口发出，命中最近的目标；爆头伤害 72，身体伤害 36。短点射比长时间连射更稳定。每弹匣 24 发，备弹无限，换弹 1.65 秒。盾牌会减速并消耗体力，不能挡住背后的攻击；丧尸攻击有可见前摇。清空每波后休息 4 秒，下一波回复 15 点生命。

## 已实现的反馈

- 角色分层：远近侧腿、护膝、盾牌、战术背心、白发、头盔、耳机、双手和独立枪械。
- 移动加减速、空中控制、跳跃缓冲、离地容错、落地尘土和脚步声。
- 跟随瞄准的枪械与手臂、枪口焰、后坐力、准星扩散、曳光线、弹壳与换弹动作。
- 身体 / 头部命中判定、命中标记、短暂停顿、击退、硬直、击倒、伤害边缘反馈和死亡统计。
- 举盾火花、金属反馈音、体力消耗与恢复；减少动态模式关闭震屏和命中停顿。
- 原创多层城市隔离区背景：月亮、天际线、废弃车辆、铁丝网、警戒路障、灯光和飘尘。
- 由代码合成的步枪、弹匣、脚步、命中、受伤与盾牌音效；可静音。

## 验证与限制

`tests/combat_test.gd` 直接运行真实战斗逻辑，检查移动、边界、跳跃、射击节奏、目标遮挡、爆头、换弹、盾牌方向、无敌间隔、丧尸前摇、暂停、波次和重开。

`tests/input_test.gd` 通过 Godot 输入事件和实时物理循环，验证 Enter、移动键、跳跃、鼠标连射、举盾、换弹、暂停与恢复、帮助和减少动态模式。当前共 **45 项检查通过**，另已用真实 OpenGL 渲染并录制 240 帧战斗演示。

这是手感验证原型，尚无正式手绘逐帧动画、游戏手柄、联机、存档、移动端适配或独立安装包。场景中的车辆、围栏和路障目前是美术背景，不能当作实体掩体。只有地面和地图边界限制移动。美术与声音的最终品质，以及鼠标操作手感，仍需实际试玩迭代。

## 项目结构

- `scripts/main.gd`：固定时间步的战斗、角色控制、敌人行为和特效。
- `scripts/actor.gd`：角色分层绘制和程序化关节动作。
- `scripts/environment.gd`：可复现的视差场景绘制。
- `scripts/hud.gd`：标题、HUD、准星、帮助和结算。
- `scripts/sound.gd`：原创合成音效。
- `tests/combat_test.gd`：无图形战斗测试。
- `tests/input_test.gd`：真实输入事件集成测试。
- `tests/visual_smoke.gd`：自动战斗演示与截图。
